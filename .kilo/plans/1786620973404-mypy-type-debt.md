## Impact Assessment

- **`verify_pin` signature change** (#6): Only caller is `auth_service.py:166`. Widening `bytes` → `Optional[bytes]` is a backward-compatible API change (existing callers passing `bytes` still work). Runtime behavior unchanged (guard at line 328 handles `None`).

The repository's `insert_merged` already has an `isinstance(payload, str)` runtime check that would convert dicts to JSON anyway (line 368-369), so behavior is identical — just moving the conversion to the call site for type safety.

- **Type annotation additions** (#1/#2 cast, #7 AsyncSession): Zero runtime impact.
