Pharmacy Suite won't open — here's what to do

Keep this file. It works without internet, without the app, and without the pharmacy network.

Your patient data is safe. The database file is separate from the program — startup problems never affect it.

Step 1 — Try the Recovery tool

  1. Open the Start Menu and search for “Pharmacy Suite Recovery”.
  2. Use its Copy Diagnostic Info and Email Support buttons.
  3. If support sent you a fix code and admin key, enter both there.

Step 2 — Email support

Email: pharmacypro.support@gmail.com

Attach the newest file from this folder (type it into the file picker):

%APPDATA%\PharmacySuite\crashes

To open that folder: press Windows key + R, paste the path above, press Enter.

What the error categories mean

CodeMeaning
FRONTEND_UNHEALTHYThe app's screen service didn't start. Usually fixed by restarting the PC.
BACKEND_UNHEALTHYThe app's data service didn't start. Another program may be using it — restart the PC and close other apps.
ERR_SESSION_EXPIREDYour session timed out. Log in again.
ERR_NO_CONNECTIONCannot reach the pharmacy server. Check WiFi/network.
EXPIRED (fix code)The fix code support sent has passed its validity window — ask for a fresh one.
VERSION_MISMATCH (fix code)The fix code is for a different app version — update first, then retry.

What support will and won't ask for

Support will ask for: the diagnostic file, the error category you see, your app version.

Support will never ask for: your password, your PIN, or remote access to “check something”. If someone does, it is a scam.

While you wait for support

  1. Restart the computer — this resolves most startup failures.
  2. Close other programs that may use the same services, then try again.
  3. If you need records urgently, they are untouched — once the app starts, everything is exactly as you left it.
